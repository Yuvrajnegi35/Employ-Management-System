# 🧑‍💼 Employee Management System

A simple React-based application that allows an admin to assign tasks to employees. This system demonstrates task management features with state persistence using local storage.

---

## 🚀 Features

- 📝 Admin can create and assign tasks to employees
- 📋 Employees can view their assigned tasks
- 🧠 State managed using React Context API
- 💾 Task data persists across sessions via Local Storage
- ⚡ Built with Vite for fast development and build performance

---

## 🛠️ Tech Stack

- **React (Vite)** – Fast and modern frontend framework
- **Context API** – For global state management
- **Local Storage** – For client-side data persistence
